# 🚗 Настоящие обгоны — теория для самостоятельного изучения

Интерактивный сайт по мастер-классу **«Настоящие обгоны»**. Ученик проходит
теорию за 15–30 минут: читает разделы, крутит интерактив, разбирает задачи
«Здесь можно?» и в конце проходит тест.

## Что внутри

- **7 разделов теории:**
  1. Что такое обгон (и чем он не является).
  2. Путь обгона и скорость + **калькулятор пути обгона**.
  3. Как подготовить обгон (алгоритм из трёх шагов, подготовка и выполнение).
  4. Когда обгон выполнять запрещается.
  5. Где обгон запрещён + разбор **«Здесь можно?»** по фото и кейсы.
  6. Сколько машин можно обгонять разом.
  7. Знак 3.20 «Обгон запрещён» и его исключения.
- **Итоговый тест** — 12 вопросов с разбором, подсчётом результата и вердиктом.
- **Прогресс** — какие разделы изучены, сохраняется в браузере (localStorage).
- Светлая адаптивная вёрстка (телефон / планшет / десктоп), логотип автошколы.

## Как запустить

Сайт статический — можно просто открыть `index.html` в браузере.

Рекомендуется локальный сервер:

```bash
cd obgony
python3 -m http.server 8777
# затем откройте http://localhost:8777
```

Для публикации подойдёт GitHub Pages (папка кладётся как есть).

## Идеи для коротких видео (на будущее)

В текущей версии видеовставок нет. Задумки на следующий мастер-класс:

1. **«Обгон своими глазами: алгоритм в реальном времени»** (1,5–2 мин).
   Вид из-за руля, без монтажа. Проговариваете три шага и показываете один обгон
   и один отказ от обгона.
2. **«Разбор мест, где обгон запрещён»** (1,5 мин).
   Короткие проезды: перекрёсток, пешеходный переход, ж/д переезд, мост.
3. **«Глазомер: хватит / не хватит»** (1–1,5 мин).
   4–5 фрагментов приближающейся встречки с выводом вслух.
4. **«Знак „Обгон запрещён“: кого можно обгонять»** (1 мин).
   Три исключения: тихоход, гужевая повозка, двухколёсное ТС.

## Источники

- Мастер-класс **«Настоящие обгоны»** (презентация и план лекции).
- ПДД РФ, глава 11 «Обгон, опережение, встречный разъезд».

> Прогресс и результат теста хранятся только в браузере ученика и никуда не отправляются.
